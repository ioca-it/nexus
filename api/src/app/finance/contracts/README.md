# Finance HTTP contracts

Estos contratos definen exclusivamente las respuestas públicas de lectura de
Finance. Las fechas se serializan como ISO 8601 y los modelos de dominio nunca
se devuelven directamente.

Las referencias internas de cliente de NEXUS y Business Central, el número de
cliente, permisos, grupos y metadatos técnicos quedan deliberadamente fuera del
contrato HTTP.
